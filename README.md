# archived-misc

An archive repo for a handful of retired practice projects. Each subdirectory is a self-contained project with its own `CMakeLists.txt`.

Common requirements: **CMake + MSVC (C++17/20/23) + Windows**. Some projects additionally need Qt6, EasyX, Eigen, OpenCV, or OpenMP.

## Projects

| Directory | What it is | Notes |
| --- | --- | --- |
| [carross](carross) | A light-weight crosshair app for Windows, lives in the tray | C++23, Win32, icon `.rc` generated by CMake |
| [mnistic](mnistic) | A training / usage / playing backend built around MNIST | Hand-rolled CNN (conv, batchnorm, dropout, ...), Eigen, OpenMP; `server/` exposes HTTP endpoints for datasets, training, evaluation, models and recognition |
| [numreco](numreco) | A handwriting digit recognizer built with Qt | Qt6 Widgets + OpenCV; `core/` is a generic CNN, `upper/` holds LeNet-5 and VGG16, `i18n/` ships 11 languages |
| [quatrank](quatrank) | A simple pixel-art tank game | Qt5/Qt6 Widgets + Multimedia; split into `core/` and `upper/`, plus an optional `editor/` map editor (`-DBUILD_EDITOR=ON`) |
| [raysim](raysim) | A CPU ray tracer | EasyX for drawing, BVH acceleration, AVX2 + OpenMP; `ffmpeg.bat` turns the rendered BMP sequence into a video |
| [structrio](structrio) | A three-in-one DSA lab experiment collection | e1 expression evaluator; e2 Huffman coder; e3 city map with A* path finding |
| [tosmako](tosmako) | A simple greedy snake game | Qt6 Widgets; split into `core/` and `game/`, assets packed via `.qrc` |

## Caveats

- Archive-only. Several `CMakeLists.txt` files hard-code local absolute paths (e.g. `D:/Program/eigen`, EasyX, OpenCV), so you will need to edit them on another machine.
- No CI, no unit tests, and no guarantee that anything still compiles against a current toolchain.
